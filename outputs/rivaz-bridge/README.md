# Rivaz bridge, Switzerland

Bridge-focused reconstruction using 36 nearby aerial photographs selected from the 101-photo Pix4D Rivaz example dataset. Images were reduced to a maximum dimension of 1600 pixels for this local demonstration. The supplied laser scans were not used.

- Interactive map: http://localhost:8000/map/project/3/task/5dcfa7d7-7bb7-475e-81b3-20d7047548e0/
- Interactive 3D model: http://localhost:8000/3d/project/3/task/5dcfa7d7-7bb7-475e-81b3-20d7047548e0/
- `bridge-source.jpg`: original aerial-photo preview showing the bridges.
- `bridge-closeup.png`: reconstructed map crop with the road and railway bridges marked.
- `map-preview.png`: image preview of the reconstructed area.
- `rivaz-map.tif`: georeferenced orthophoto.
- `rivaz-3d-model.glb`: textured 3D model.
- `rivaz-point-cloud.laz`: compressed georeferenced point cloud.
- `processing-report.pdf`: reconstruction report.

The survey includes the village, vineyards, and bridges near the lake. This is an aerial demonstration with reduced-quality processing; it does not provide complete bridge underside coverage or an engineering inspection.

Source and credit: Pix4D, Rivaz example dataset, https://support.pix4d.com/hc/en-us/articles/360000235126 . Refer to the provider's usage terms before redistribution or commercial use.

WebODM must be running for the interactive links to work. Local output files remain usable independently.

Processing completed successfully. The exported point cloud contains 729,054 points. The map uses 15 cm pixels; the reduced source survey has an estimated average ground sampling distance of 8.23 cm. These figures do not establish survey accuracy.
